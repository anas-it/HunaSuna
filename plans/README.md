# Plans

В этой папке лежат рабочие планы проекта HunaSuna.

| Папка | Назначение |
| --- | --- |
| `active-plans/` | Текущие планы в работе. |
| `completed-plans/` | Завершенные планы и история этапов. |

## Правила

- Постоянные спеки остаются в `../specification/`.
- Активный план после завершения переносится из `active-plans/` в `completed-plans/`.
- При переносе важного плана обновлять ссылки и `../CHANGELOG.md`.
