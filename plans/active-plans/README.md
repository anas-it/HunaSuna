# Active Plans

В этой папке лежат только текущие рабочие планы. Постоянные спецификации остаются в `specification/`.

## Текущие планы

- `01-app-store-публикация.md` - пошаговая подготовка и публикация мобильного приложения HunaSuna в App Store.

## Правила

- Один план не должен одновременно лежать в `plans/active-plans/` и `plans/completed-plans/`.
- Когда план выполнен, его нужно перенести в `plans/completed-plans/`.
- При важном переносе или завершении обновлять `CHANGELOG.md`.
- Если путь к плану упоминается в спеках, скилах или `AGENTS.md`, обновлять ссылки вместе с переносом.
