# .skills

Эта папка нужна как быстрый вход в скилы проекта.

Рабочие скилы остаются в обычной папке:

- `../skills/`

Почему так: в проектных правилах и спецификациях уже закреплен путь `skills/`. Поэтому мы не переносим файлы внутрь `.skills/`, чтобы не сломать ссылки и привычный порядок.

## Текущие скилы

- `../skills/1-project-specs/SKILL.md`
- `../skills/2-nextjs-fullstack/SKILL.md`
- `../skills/3-database/SKILL.md`
- `../skills/4-security-and-auth/SKILL.md`
- `../skills/5-interface/SKILL.md`
- `../skills/6-mobile-app/SKILL.md`

## Правило

Если нужно менять скил, править нужно файлы в `../skills/`. Эта папка остается навигацией, чтобы в Explorer было понятно, где искать инструкции.
