# Папка scripts

`scripts/` содержит ручные технические скрипты, которые запускаются разработчиком.

## Скрипты

| Файл | Назначение |
| --- | --- |
| `api-smoke.mjs` | Быстрая проверка основных API-сценариев. Запускается через `npm run test:api`. |

## Правила

- Не хранить здесь код, который нужен приложению во время обычной работы.
- Если логика нужна production API, ей место в `server/services`, `server/jobs` или `app/api`.
- Скрипты должны быть безопасны для локальной разработки и не должны удалять пользовательские данные без явного предупреждения.
