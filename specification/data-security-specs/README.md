# Data And Security Specs

Данные, безопасность, доступ и юридические ограничения.

| Файл | Для чего нужен |
| --- | --- |
| `05-data.md` | Сущности, поля, хранение и жизненный цикл данных. |
| `07-security.md` | Пароли, доступ, приватность и ограничения. |
| `08-roles-and-access.md` | Роли и правила видимости данных. |
| `10-legal.md` | Ограничения, чтобы проект не выглядел как финансовый сервис. |

Эта группа особенно важна перед изменением API, базы данных и пользовательских данных.
