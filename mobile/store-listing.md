# HunaSuna Store Listing

## Короткое описание

HunaSuna помогает аккуратно вести учет информации о переводах, контактах и записях.

## Подзаголовок для App Store

Учет записей и контактов

## Полное описание

HunaSuna - удобный инструмент для учета информации о переводах. Приложение помогает хранить контакты, создавать записи, быстро находить нужную историю и держать важные данные под рукой.

HunaSuna не переводит деньги, не хранит деньги и не является банком, обменником, платежной системой или финансовым посредником. Это рабочий журнал для аккуратного учета информации, которую пользователь добавляет самостоятельно.

### Что можно делать в HunaSuna

- Создавать записи с данными отправителя и получателя.
- Сохранять сумму, валюту, курс, дату и время записи.
- Добавлять и редактировать контакты.
- Быстро выбирать контакт при создании записи.
- Искать записи по имени, фамилии или номеру телефона.
- Искать контакты по началу имени, фамилии или номера.
- Добавлять важные записи в избранное.
- Сортировать записи по дате или алфавиту.
- Переносить записи в удаленные и восстанавливать их в течение срока хранения.
- Работать с теми же данными, что и на сайте HunaSuna.

### Почему это удобно

HunaSuna убирает хаос из записей и контактов. Вместо разрозненных заметок, переписок и ручного поиска пользователь получает понятный список записей, быстрый поиск, избранное и историю по контактам.

Приложение подходит для тех, кому важно быстро проверить, кто участвовал в записи, какая была сумма, валюта, курс и когда запись была создана.

### Безопасность и приватность

Данные пользователя доступны только после входа в аккаунт. Мобильное приложение обращается к защищенному API HunaSuna и использует ту же базу данных, что и web-версия. Пароли не хранятся в открытом виде.

Политика конфиденциальности: https://hunasuna.pro/privacy

## Данные для Data Safety / App Privacy

Предварительно указать, что приложение может обрабатывать:

- Account info: логин, e-mail и телефон, если пользователь их указал.
- User content: контакты и записи, созданные пользователем.
- App activity / security data: попытки входа, сессии, IP-адрес и технические действия безопасности.

Данные используются для работы аккаунта, записей, контактов, поиска, восстановления доступа и защиты аккаунта.
