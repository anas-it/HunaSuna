# Папка prisma

`prisma/` содержит модель данных и миграции PostgreSQL.

## Что где лежит

| Путь | Назначение |
| --- | --- |
| `schema.prisma` | Основная Prisma schema. |
| `migrations/` | История изменений базы данных. |
| `migrations/migration_lock.toml` | Служебный файл Prisma. |

## Правила

- Не менять старые примененные миграции вручную, если для этого нет отдельной осознанной задачи.
- Для новых изменений схемы создавать новую миграцию.
- Архивные записи остаются в техническом архиве базы данных без пользовательского доступа.
- Пользовательские API не должны отдавать внутренние архивные и служебные поля.

## Команды

```powershell
npm run prisma:generate
npm run prisma:migrate
npm run prisma:studio
```
