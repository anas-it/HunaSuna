# Папка server

`server/` содержит серверную часть HunaSuna. Это главный дом для бизнес-логики, авторизации, валидации, фоновых задач и технических логов.

## Папки

| Папка | Назначение |
| --- | --- |
| `auth/` | Сессии, текущий пользователь, права доступа, password helpers. |
| `db/` | Prisma client и будущие сложные запросы. |
| `services/` | Бизнес-логика пользователей, контактов, записей, поиска, архива. |
| `validators/` | Zod-схемы и проверка входящих данных. |
| `jobs/` | Фоновые задачи. |
| `logs/` | Технические логи безопасности. |

## Правила

- Пользователь должен видеть только свои данные.
- Удаленную запись нельзя редактировать.
- После 7 дней удаленная запись исчезает из пользовательского интерфейса и остается только в техническом архиве.
- API должен получать из services уже подготовленные публичные данные без лишних полей.
- SMS-сервисы в первой версии не используются.
