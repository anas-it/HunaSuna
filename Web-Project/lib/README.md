# Папка lib

`lib/` содержит общие технические помощники, которые могут использовать web-страницы, API и server-код.

## Файлы

| Файл | Назначение |
| --- | --- |
| `constants.ts` | Общие лимиты и константы проекта. |
| `date.ts` | Форматирование и работа с датами. |
| `format.ts` | Форматирование значений для интерфейса. |
| `pagination.ts` | Общая логика пагинации. |
| `phone.ts` | Нормализация и обработка телефонов. |
| `utils.ts` | Небольшие общие helpers. |

## Правила

- Не хранить здесь бизнес-логику HunaSuna.
- Не добавлять сюда код, который напрямую зависит от текущего пользователя или Prisma.
- Если helper начинает знать правила записей, контактов или архива, ему место в `server/services`.
