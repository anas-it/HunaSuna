# Папка components

`components/` содержит web UI-компоненты. Здесь не должна жить бизнес-логика доступа к данным.

## Текущие папки

| Папка | Назначение |
| --- | --- |
| `ui/` | Базовые UI-компоненты. |
| `layout/` | Навигация, оболочка страниц, логотип, общие элементы раскладки. |
| `forms/` | Общие помощники форм. |
| `contacts/` | Действия и UI для контактов. |
| `records/` | Список, форма и действия записей. |
| `settings/` | Личный кабинет и настройки. |

## Правила

- Компоненты должны получать готовые данные через props или server actions.
- Проверки владельца данных, архивирования и удаления должны оставаться в `server/services`.
- Если появится крупная отдельная зона UI, можно создать новую папку рядом с текущими.
