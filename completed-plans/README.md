# Completed Plans

В этой папке хранятся планы, которые уже выполнены, и подробные описания уже сделанных этапов проекта.

Когда активный рабочий план завершен, его нужно перенести сюда из `active-plans/` и при необходимости добавить запись в `CHANGELOG.md`.

Спеки проекта сюда не переносить. Спеки остаются в `specification/`.

## Список завершенных планов

- `01-подготовка-спецификаций.md` - подготовка базовых спецификаций.
- `02-базовая-web-разработка.md` - базовая web-разработка.
- `03-организация-планов.md` - организация активных и завершенных планов.
- `04-мобильная-разработка.md` - разработка мобильного приложения.
