- Next.js fullstack: `2-nextjs-fullstack`;
- база данных: `3-database`;
- безопасность и авторизация: `4-security-and-auth`;
- интерфейс рабочего инструмента: `5-interface`;
- мобильное приложение: `6-mobile-app`.
