# Skills HunaSuna

Эта папка хранит рабочие скилы проекта HunaSuna.

Скилы помогают Codex и разработчику быстро открыть правила по важным направлениям проекта:

- продукт и спецификации: `1-project-specs`;
- Next.js fullstack и общий backend: `2-nextjs-fullstack`;
- база данных: `3-database`;
- безопасность и авторизация: `4-security-and-auth`;
- интерфейс рабочего инструмента: `5-interface`;
- мобильное приложение: `6-mobile-app`.
