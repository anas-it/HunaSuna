# Интерфейс HunaSuna

## Цель

Помогать делать интерфейс HunaSuna простым, спокойным и удобным для взрослых пользователей, которые хотят быстро записывать и находить информацию без хаоса.

## Основные правила

- Не перегружать сайт лишними цветами.
- Не делать сайт похожим на банк, обменник или платежную систему.
- Главный смысл интерфейса - учет информации.
- Использовать слово “запись”, а не “тикет”.
- Действия должны быть понятны без обучения.
- Важные кнопки должны быть видны там, где пользователь их ожидает.
- Интерфейс должен хорошо работать на компьютере и мобильном экране.

## Основные разделы

- Главная.
- Контакты.
- Создание записи.
- История записей.
- Поиск.
- Удаленные.
- Личный кабинет.
- Настройки.

## Запись

Форма записи должна позволять:

- выбрать существующий контакт или ввести данные вручную;
- указать отправителя;
- указать получателя;
- указать сумму;
- выбрать валюту;
- указать курс;
- сохранить запись.

При ручном вводе номер телефона необязателен.

## Контакты

Контакт должен показывать:

- имя;
- фамилию;
- мобильный номер;
- историю связанных записей.

История контакта показывает записи, суммы и то, сколько контакт передавал и получал.

## Удаленные

Раздел “Удаленные” должен быть отдельным.

В удаленной записи должны быть доступны:

- просмотр;
- восстановление.

Редактирование удаленной записи запрещено, пока она не восстановлена.

Нужно показывать, сколько дней осталось до окончательного исчезновения из пользовательского интерфейса.

После 7 дней запись исчезает из пользовательского интерфейса окончательно, но может храниться в архиве администрации 3 месяца.

## Поиск

Поиск должен быть простым и работать по:

- контакту;
- номеру телефона.

Поиск по дате и фильтрации по валюте в первой версии не должно быть.

Если по номеру ничего не найдено, показывать понятное пустое состояние.

## Тон интерфейса

Тексты должны быть короткие и спокойные.

Ошибки писать человеческим языком:

- “Неверный секретный ответ”
- “Запись не найдена”
- “Запись восстановлена”

Не использовать сложные технические слова в интерфейсе.
