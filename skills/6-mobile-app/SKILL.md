# Мобильное приложение HunaSuna

## Цель

Помогать делать мобильное приложение HunaSuna как отдельный клиент общего backend.

Мобильное приложение должно использовать те же аккаунты, контакты, записи, поиск, удаленные записи и правила безопасности, что и web-версия.

## Перед работой читать

- `specification/mobile-specs/15-мобильное-приложение.md`;
- `specification/technical-specs/16-api-contract.md`;
- `specification/mobile-specs/17-мобильная-безопасность.md`;

## Технические правила

- Использовать React Native, Expo и TypeScript.
- Хранить мобильный проект в `mobile`.
- Не создавать отдельный backend для мобильного приложения.
- Использовать API из `app/api`.
- Для защищенных запросов использовать `Authorization: Bearer <session token>`.
- Хранить session token только в защищенном хранилище устройства.
- В native-приложении использовать Expo SecureStore; в Expo Web/dev preview для проверки использовать только `sessionStorage`.
- Не хранить `DATABASE_URL`, `CRON_SECRET` и серверные секреты в мобильном коде.

## Продуктовые правила

- Описывать HunaSuna как инструмент учета информации о переводах.
- Использовать слово “запись”, а не “тикет”.
- Не добавлять реальные платежи, карты, кошельки, балансы, комиссии или статус перевода.
- Не добавлять удаление аккаунта пользователя в первую мобильную версию.
- Не делать поиск по дате в первой версии.
- Восстановление пароля делать только через секретный вопрос и ответ.

## Экраны первого мобильного MVP

- вход;
- регистрация;
- восстановление пароля;
- главная;
- контакты;
- контакт и история контакта;
- записи;
- создание записи;
- просмотр записи;
- редактирование записи;
- поиск;
- удаленные записи;
- настройки;
- экран ошибки сети.

## Проверка качества

Перед завершением мобильной задачи проверять:

- работает ли экран на маленьком экране;
- не хранится ли token небезопасно;
- не раскрывает ли API лишние поля;
- не видит ли пользователь чужие данные;
- есть ли понятные ошибки сети и истекшей сессии;
- не появилось ли ощущение банка, кошелька или платежной системы.
