# .agents

Эта папка нужна как быстрый вход в правила работы AI-агентов с проектом.

Главный файл правил остается в корне:

- `../AGENTS.md`

Почему так: Codex и другие агенты обычно ищут `AGENTS.md` в корне проекта. Поэтому мы не переносим этот файл внутрь `.agents/`, чтобы не сломать автоматическое чтение правил.

## Что читать

1. `../AGENTS.md` - обязательные правила для агента.
2. `../README.md` - карта проекта для человека.
3. `../specification/README.md` - карта спецификаций.
4. `../plans/active-plans/README.md` - текущая работа.

## Правило

Если меняются главные правила агента, править нужно `../AGENTS.md`. В эту папку можно добавлять только вспомогательные заметки и карты.
