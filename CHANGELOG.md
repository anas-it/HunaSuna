# Changelog

## 2026-06-11

- Рабочие планы перенесены в общую папку `plans/`: текущие лежат в `plans/active-plans/`, завершенные - в `plans/completed-plans/`.
- Имена папок в `skills/` переведены на английский: `skills/1-project-specs/`, `skills/3-database/`, `skills/4-security-and-auth/` и `skills/5-interface/`.
- Имена файлов в `specification/` переведены на английский, а ссылки в README, AGENTS, скилах, спеках и планах обновлены.
- Папка `specification/` упорядочена по группам: `specification/global-specs/`, `specification/functional-specs/`, `specification/data-security-specs/`, `specification/technical-specs/`, `specification/mobile-specs/` и `specification/planning-specs/`.
- Добавлены `.agents/`, `.skills/` и `.vscode/settings.json`: в VS Code скрываются служебные кэши, зависимости, логи и сгенерированные файлы, а правила агентов и скилы получили понятные навигационные входы.
- Наведена структура навигации по проекту: добавлены README-карты для корня, `app/`, `components/`, `server/`, `lib/`, `mobile/`, `prisma/` и `plans/active-plans/`; из рабочей папки убраны пустые директории старого SMS/verify-phone сценария.
- Первый App Store release мобильного приложения настроен как iPhone-only: в `mobile/app.json` отключен `ios.supportsTablet`.
- Production iOS build мобильного приложения привязан к EAS environment `production`; в EAS добавлены публичные URL-переменные `EXPO_PUBLIC_API_BASE_URL` и `EXPO_PUBLIC_WEB_API_BASE_URL` со значением `https://hunasuna.pro`.
- Добавлен активный план `plans/active-plans/01-app-store-публикация.md` для пошаговой публикации мобильного приложения HunaSuna в App Store через EAS Build, TestFlight и App Store Connect.
- Правило удаления синхронизировано: удаленная запись 7 дней видна в разделе `Удаленные`, затем исчезает из web/mobile интерфейса и остается только в техническом архиве базы данных без пользовательского доступа.
- Cron `/api/cron/deleted-records` настроен для ежедневного архивирования записей, срок восстановления которых истек; очистка технического архива по сроку убрана.
- API записей, контактов и профиля переведен на явные `select`, чтобы не отдавать лишние внутренние поля пользователю.
- Регистрация теперь поддерживает необязательные телефон, email или оба значения.
- Время записи определяется backend по IP/infrastructure headers, мобильный клиент больше не отправляет timezone-заголовок.
- Native mobile app хранит session token в SecureStore, Expo Web/dev preview использует `sessionStorage`, production web-сайт остается на httpOnly cookie.
- План мобильной разработки перенесен из `plans/active-plans/` в `plans/completed-plans/04-мобильная-разработка.md`.

## 2026-06-04

- Мобильное приложение подключено к общему API web-версии: добавлены рабочие разделы контактов, записей, поиска, удаленных записей и настроек вместо заглушки.
- Главная навигация мобильного приложения переведена на нижнюю панель с крупной центральной кнопкой создания записи; поиск вынесен в центр главного экрана.
- Нижние иконки мобильного приложения оформлены как мягкие цветные плитки, а главный поиск заменен на поле ввода с быстрым запуском поиска.
- Нижние иконки мобильного приложения заменены на прозрачные контурные иконки; центральная кнопка создания записи получила круглую обводку без заливки.
- Нижняя навигация мобильного приложения выровнена по одному уровню; центральная кнопка приведена к общему размеру, текст уменьшен, а анимация нажатия применяется только к иконке.
- Главный экран мобильного приложения получил иконку рядом с `HunaSuna`, поднятый поиск с анимированной стрелкой и список записей под поиском.
- На главном экране мобильного приложения убран бренд `HunaSuna`, сверху оставлен логин пользователя; выход из аккаунта перенесен в мобильные настройки.
- Исправлен focus-эффект мобильных полей ввода в Expo Web: стандартная оранжевая рамка заменена на оформление приложения.
- В мобильном приложении убраны подписи под заголовками разделов; форма записи переработана: выбор контакта открывается в модальном окне и автоматически заполняет поля.
- Мобильный раздел `Контакты` получил более компактную форму и улучшенные карточки контактов с иконкой удаления без текстовой подписи.
- Мобильный раздел `Контакты` перестроен вокруг списка контактов: форма добавления или редактирования теперь открывается только по кнопке `Добавить` или иконке изменения.
- Мобильный раздел `Контакты` получил компактные карточки только с именем и фамилией; телефон, WhatsApp и подробности контакта открываются отдельным окном после удержания карточки.
- Карточки контактов в мобильном списке уплотнены до одной строки с действиями справа, чтобы один контакт не занимал слишком много места.
- Из компактных карточек контактов убраны буквенные аватары, чтобы длинные имя и фамилия помещались лучше и могли переноситься на две строки.
- В мобильный раздел `Контакты` добавлен живой поиск по имени, фамилии и номеру с совпадением от начала значения.
- Мобильный раздел `Настройки` переработан в компактный личный кабинет с раскрываемыми блоками и более удобными полями с иконками.
- На экран входа мобильного приложения добавлен адаптированный анимированный бренд-блок HunaSuna перед формой авторизации.
- Анимация бренд-блока HunaSuna на экране входа улучшена: буквы оставлены статичными для четкости, а визуальное движение перенесено на мягкую подсветку.
- Бренд-блок HunaSuna на экране входа очищен от внешнего свечения, знак внутри сделан более читаемым и спокойным.
- Бренд-блок HunaSuna на экране входа обновлен по новому горизонтальному референсу со знаком, названием и подписью `Smart Money Information`.
- Внутренняя часть знака HunaSuna на экране входа упрощена: буквы выровнены без наложений, анимация оставлена отдельно от текста.
- На экран входа установлен новый круглый логотип HunaSuna из предоставленного изображения; под ним оставлен текст `HunaSuna`, а анимация перенесена на мягкий ореол и световой проход.
- Логотип HunaSuna на экране входа заменен на высококачественный raster-export с `@2x` и `@3x` версиями; визуальный эффект сделан спокойнее.
- Надпись `HunaSuna` под логотипом на экране входа возвращена к прежнему двухцветному стилю.
- Экран входа мобильного приложения адаптирован под клавиатуру: при вводе логина и пароля логотип сжимается, форма поднимается и остается доступной.
- На экране входа мобильного приложения убрана внешняя touch-обертка формы, из-за которой поля логина и пароля могли не получать фокус на телефоне.
- Мобильный раздел `Записи` получил компактные карточки без телефонов в списке, поиск по лупе и подробное модальное окно записи по долгому удержанию карточки.
- Мобильный раздел `Записи` получил удержание 1.5 секунды для подробностей, сортировку по дате/алфавиту, скрытие списка во время формы создания и переход к новой записи после сохранения.
- В мобильных формах записи и контакта убраны дублирующие подписи над полями; при открытой форме контакта список контактов снизу скрывается.
- Списки записей, поиска, удаленных записей и истории контакта в мобильном приложении переведены на пагинацию по 15 записей; сортировка остается внутри выбранной страницы.
- Мобильный поиск получил подсказки контактов по имени, фамилии и номеру, а выбор контакта в форме записи получил поиск внутри модального окна.
- Поиск контактов в мобильных подсказках теперь ищет имя, фамилию и номер по началу значения, чтобы цифры из середины номера не давали лишние совпадения.
- Общий поиск записей теперь ищет имя, фамилию и телефон по началу значения, чтобы короткий ввод не показывал случайные совпадения из середины номера.
- В разделе `Записи` убраны контактные подсказки под полем поиска; поиск теперь показывает только записи и умеет находить их по паре имя+фамилия контакта.
- В разделе `Записи` контактные подсказки возвращены в аккуратном виде: показываются только реальные совпадения, а выбор контакта запускает поиск записей по `contactId`.
- Поиск записей по телефону стал устойчивее к пробелам и символам за счет нормализованных search-полей в `Record`.
- Mobile API client больше не отправляет timezone: время определяется backend по IP/infrastructure headers, а client корректно обрабатывает истекшую сессию и показывает понятные ошибки API-валидации.
- API больше не показывает пользователю внутренние Prisma-ошибки и stack trace; технические детали остаются только в логах сервера.
- CORS для Expo Web больше не разрешает отдельный timezone-заголовок: вход и API-запросы из `localhost:8081` работают через стандартные `Authorization`, `Content-Type` и `X-HunaSuna-Client`.
- CORS для Expo Web больше не привязан к одному LAN-IP, а EAS config перенесен в папку `mobile`.
- В mobile и web убраны лишние описания под заголовками разделов; нижняя мобильная навигация оставлена без видимых подписей.
- Добавлены спеки `specification/mobile-specs/15-mobile-app.md`, `specification/technical-specs/16-api-contract.md` и `specification/mobile-specs/17-mobile-security.md`.
- Добавлен скил `skills/6-mobile-app` и обновлен README скилов.
- Активный мобильный план обновлен под React Native, Expo, TypeScript, общий API и bearer session token.
- Восстановление пароля зафиксировано только через секретный вопрос и ответ; старые `PasswordRecoveryCode` и `emailUsableForRecovery` удалены из Prisma schema.
- Поиск по дате исключен из первой web/mobile версии; поиск остается по контакту и номеру телефона.
- API авторизации и настроек подготовлены для мобильного клиента без отдельного backend.
- Из `.env` и `.env.example` убраны устаревшие `BETTER_AUTH_*`, в mobile добавлен `expo-secure-store`.
- Mobile-проект понижен с Expo SDK 56/55 до SDK 54 для совместимости с Expo Go на телефоне пользователя.
